# Getting help

Ciphered Private Bus is maintained in the open without paid support.

## Look first

- Check the specification and documentation in `docs/` (once published).
- Search existing [issues](https://github.com/HunterEwok/ciphered-private-bus/issues?q=is%3Aissue),
  open and closed: your question or issue may already be answered.

## Where to go

| You have | Go to |
|---|---|
| A question, proposal, or protocol idea | An issue with the **Feature request** form |
| A bug in the code or specification | An issue with the **Bug report** form |
| A security vulnerability | A private report — never a public issue: see [SECURITY.md](SECURITY.md) |

Responses are provided on a best-effort basis; there is no guaranteed response time except
for security reports as described in [SECURITY.md](SECURITY.md).
