# Ciphered Private Bus Documentation

This directory holds the formal specification and architectural documentation for
**Ciphered Private Bus** (**CPB**), licensed under
[CC BY 4.0](../LICENSES/CC-BY-4.0.txt).

## Planned sections

- **Protocol specification** — uniform wire framing, endpoint addressing, decentralized
  access arbitration, replay-protected command dispatch, post-quantum end-to-end
  encryption, and root recovery without a central authority.
- **Threat model** — adversary capabilities, trust boundaries, and security invariants.
- **Cryptography** — key schedule, hybrid post-quantum primitives, and test vectors.
